# Documentation languages / 文档语言

This repository keeps its public documentation in Simplified Chinese and English. The Chinese `README.md` is the primary, user-facing document shown on the repository landing page; `README.en.md` mirrors it in English. Command names, file names, flags, table names, and identifiers must stay identical across both languages.

本仓库的公开文档同时提供简体中文和英文。中文版 `README.md` 是仓库首页默认展示的主文档，英文由 `README.en.md` 镜像提供。命令名、文件名、参数、表名和标识符必须在两种语言中保持一致。

| 中文 | English |
| --- | --- |
| [README.md](README.md) | [README.en.md](README.en.md) |

When you change user-visible behavior, update both README files in the same pull request. If a translation is temporarily behind, open an issue labelled `translation` rather than guessing about data-safety behavior.

修改面向用户的行为时，应在同一个 Pull Request 中同步更新两份 README。若译文暂时落后，请创建带有 `translation` 标签的 Issue，不要自行猜测与数据安全相关的行为。
